# HR Attrition Dashboard Analysis

## Deskripsi Proyek

Attrition atau turnover karyawan merupakan salah satu tantangan utama dalam pengelolaan sumber daya manusia. Tingginya tingkat attrition dapat meningkatkan biaya rekrutmen, mengganggu produktivitas tim, serta mempengaruhi stabilitas organisasi.

Pada proyek ini dilakukan analisis HR Attrition menggunakan Tableau Public untuk mengidentifikasi faktor-faktor yang berhubungan dengan tingginya tingkat turnover karyawan. Dashboard dirancang untuk membantu manajemen dalam memahami pola attrition dan mendukung pengambilan keputusan berbasis data.

---

## Tujuan Analisis

Proyek ini bertujuan untuk:

* Mengidentifikasi departemen dengan tingkat attrition tertinggi.
* Menganalisis hubungan antara tingkat kepuasan kerja dan attrition.
* Mengevaluasi pengaruh jarak tempuh karyawan terhadap risiko resign.
* Menyediakan dashboard interaktif untuk mendukung analisis HR.

---

## Dataset

Dataset HR Attrition berisi informasi terkait kondisi karyawan dalam perusahaan, meliputi:

| Variabel         | Deskripsi                         |
| ---------------- | --------------------------------- |
| Department       | Departemen karyawan               |
| Job Title        | Jabatan karyawan                  |
| Gender           | Jenis kelamin                     |
| Job Satisfaction | Tingkat kepuasan kerja            |
| Commute Distance | Jarak tempuh ke tempat kerja      |
| Attrition Status | Status karyawan (bertahan/resign) |

## Dashboard Overview

Dashboard menampilkan beberapa indikator utama yang berkaitan dengan attrition karyawan, antara lain:

### Attrition by Department

Menampilkan jumlah karyawan yang resign berdasarkan departemen.

### Job Satisfaction vs Attrition

Menunjukkan hubungan antara tingkat kepuasan kerja dan tingkat turnover karyawan.

### Commute Distance Analysis

Menganalisis pengaruh jarak tempuh terhadap keputusan karyawan untuk resign.

### Interactive Filters

Dashboard dilengkapi filter berdasarkan:

* Gender
* Job Title
* Attrition Status

---

## Business Insight

### 1. Departemen dengan Attrition Tertinggi

Departemen **Tech & Product** memiliki jumlah attrition tertinggi dibandingkan departemen lainnya.

### 2. Kepuasan Kerja dan Turnover

Sebagian besar karyawan yang resign memiliki tingkat kepuasan kerja rendah hingga menengah, khususnya pada skor kepuasan 1 dan 2.

### 3. Jarak Tempuh

Kelompok karyawan dengan jarak tempuh **21–30 km** menunjukkan jumlah resign tertinggi dibanding kategori jarak lainnya.

## Rekomendasi

Berdasarkan hasil analisis, perusahaan dapat mempertimbangkan beberapa langkah berikut:

### Employee Engagement Program

Meningkatkan keterlibatan karyawan pada departemen dengan tingkat attrition tinggi.

### Monitoring Kepuasan Kerja

Melakukan evaluasi berkala terhadap tingkat kepuasan karyawan untuk mengidentifikasi potensi turnover lebih awal.

### Career Development

Menyediakan program pengembangan karier dan apresiasi karyawan.

### Flexible Working Policy

Mempertimbangkan penerapan sistem kerja hybrid atau flexible working untuk mengurangi beban mobilitas karyawan dengan jarak tempuh jauh.

---

## Kesimpulan

Analisis menunjukkan bahwa tingkat attrition dipengaruhi oleh beberapa faktor utama, yaitu departemen kerja, tingkat kepuasan kerja, dan jarak tempuh menuju tempat kerja.

Dashboard interaktif yang dibangun menggunakan Tableau Public membantu menyajikan informasi secara lebih mudah dipahami dan mendukung pengambilan keputusan berbasis data dalam pengelolaan sumber daya manusia.
